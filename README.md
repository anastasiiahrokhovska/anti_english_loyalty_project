# ANEI ENGLISH — Loyalty Card & Booking Bot

Спрощена версія: **без акаунтів, паролів, Firebase Authentication та особистих кабінетів**.

## Як це працює

- Учасник відкриває скретч-картку й форму запису через Telegram-бота.
- Обирає розсилку та тему, додає посилання на свій канал і надсилає заявку.
- Бот надсилає заявку адміністраторці та показує посилання на оплату Monobank.
- Після перевірки оплати адміністраторка вручну оновлює скретч-картку та надсилає її учаснику в директ.

Картки лояльності й кількість штампів адміністраторка веде вручну. Скретч-ефект — лише візуальний, він не перевіряє оплату та не змінює кількість штампів автоматично.

## Запуск у PyCharm

1. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
2. У `bot.py` вкажіть власні `BOT_TOKEN`, `ADMIN_ID` та URL розміщеного `index.html`.
3. Переконайтеся, що `WEB_APP_URL` веде на сторінку, опубліковану через HTTPS.
4. Запустіть `bot.py`.
